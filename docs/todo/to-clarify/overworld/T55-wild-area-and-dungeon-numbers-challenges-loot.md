# T55 · Wild Area and Dungeon: Numbers, Challenges and Loot

**Status:** To clarify — the build of both places is decided ([vision.md §4](../../../vision.md#4-where-battles-happen)); numbers, lists and the generator are open. Takes the place of T21 and T22.
**Prerequisites:** none. A dungeon run of an earlier design exists in the build (`godot/overworld/dungeon.tscn`, `expedition.gd`); it was not checked against the frame.
**Sources:** [vision.md §4](../../../vision.md#4-where-battles-happen); [battle_ingame.md §2–§4](../../../battle_ingame.md#2-team-sizes-and-the-end-of-a-battle); [overworld.md §4.2](../../../overworld.md#42-defeat).

**Open for the user:**

| Topic | Questions |
|---|---|
| Wild area | How many encounters a day; how far ahead a rare encounter is announced and how long it stays; whether an older zone stays worth a visit; what a lost battle costs besides the day AP |
| Dungeon run | The number of battles (four to six is a working value); the part of the loot a defeat costs; what a rest node does; whether nodes without a battle exist; whether an older dungeon stays worth a visit |
| Challenge and harvest | The list of challenges and whether a dungeon has one or several; the yield of a harvest against a run |
| Loot | What each place gives in numbers, by stage ([vision.md §7](../../../vision.md#7-making-things)) |
| Opponents | Wild monsters only, or tamers too; if tamers, the contract of [battle_ingame.md §7](../../../battle_ingame.md#7-catching) applies |
| Boards | Where the battlegrounds of the places come from: written by hand in the map editor, generated, or both; how a generated one stays a puzzle with ends and board events |
| One-time realms | Dropped with the frame unless the user wants them beside the dungeon |

- **Done when:** every row is decided and written into [vision.md](../../../vision.md), [overworld.md](../../../overworld.md) or [battle_ingame.md](../../../battle_ingame.md), with lines in [decisions.md](../../../decisions.md).
