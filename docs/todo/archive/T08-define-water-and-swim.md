# T08 · Define Water and Swim

**Status:** Decided by the user (2026-11-10): Water ground and the Swim movement mode are removed from the current design. Reason: protected Water that skills can influence would need a second parallel ground set (hazard/blessed variants), which contradicts "few uniform rules"; Rubble and Mountain already cover movement-cost terrain. Applied in Battle §4.7 and Skills §3/§5/§8.2/§10. Re-introduction is only tracked under [Potential Extensions](../ideas.md).
**Prerequisites:** none.
**Sources:** Battle [battle.md §4.5](../../battle.md#45-ground); Skills [skills.md §3](../../skills.md#3-what-a-skill-does-and-creates), [skills.md §5](../../skills.md#5-movement-kinds).
- Not affected: Overworld building adjacency tags ("water" for Qi Spring/Spirit Pond, Immortal-city layout) are a separate meta concept and still need an explicit decision if Water is dropped from the whole game (see Potential Extensions).
